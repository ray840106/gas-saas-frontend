# 瓦斯行前端 (Vue 3 + TypeScript + Vite)

```bash
npm install
npm run dev      # 開發模式
npm run build    # 打包
```

後端網址由 `VITE_API_BASE_URL` 指定（見 `.env.production`）。

## 畫面切換

用網址 hash 切換，不需要安裝 vue-router：

| 網址 | 畫面 | 使用者 |
| --- | --- | --- |
| `/` | 叫瓦斯表單（LIFF） | 客戶 |
| `/#/driver` | 🚚 送貨路線規劃 | 送瓦斯的師傅 |
| `/#/dashboard` | 後台儀表板 | 老闆 |

## 🚚 送貨路線規劃（`src/components/DriverRoute.vue`）

給師傅在手機上使用，操作流程：

1. **選起點** — 目前位置（GPS）／瓦斯行（後端 `DEPOT_*` 設定）／手動輸入地址，
   也可以勾選「送完要繞回出發點」把回程里程算進去。
2. **勾選訂單** — 預設全選當前所有待配送訂單，可依日期篩選。
3. **排出最佳路線** — 後端算出最短順序，同一個地址的多張訂單會自動併成一站。
4. **導航** — 每一站都有「🧭 導航」直接開啟 Google 地圖；
   也可以用「🗺️ 在 Google 地圖開啟整趟」一次帶入所有站點
   （Google 單一連結最多 9 個中途點，超過會自動分段）。
5. **回報送達** — 按「✅ 已送達」更新訂單狀態，畫面上會打勾並顯示剩餘站數。

路線與已送達進度會存在瀏覽器的 localStorage，師傅中途切到 LINE 或不小心關掉頁面，
12 小時內回來還看得到同一份路線。

> 想把這頁掛進 LINE 官方帳號的圖文選單，網址填 `https://<你的網域>/#/driver` 即可。

起點設定（用目前位置還是瓦斯行、要不要算回程、手動輸入的地址）也會記在 localStorage，
師傅每天開啟時維持上次的選擇。

## 📒 叫瓦斯表單的地址（`src/components/OrderForm.vue`）

客戶不用每次重打地址：

- **自動帶出**：開啟 LIFF 時讀取這位客戶的常用地址，下拉選單預設就是最近使用的那一個。
- **下拉選擇**：常用地址以「標籤｜地址」呈現（例如「住家｜台北市…」），
  沒存過地址的舊客戶也會自動帶出過去訂單用過的地址，避免重打錯字。
- **要換地址才輸入**：按「✏️ 送到其他地址」才會出現輸入框，可以順便替它取名（住家／店面）。
- **地址防呆**：新地址離開輸入框時會自動跟地圖核對，找得到就顯示比對到的完整地址，
  找不到會提醒確認門牌，送出前再問一次，避免師傅跑到一半找不到路。
- **送出即記住**：下單成功後該地址自動存進地址簿並設為預設，下次直接選取。
- 選錯或不再使用的地址可以用「🗑 移除這個地址」刪掉。
